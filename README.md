# Employee Management System

A full-stack Employee Management System built using **Spring Boot** for the backend and **React (Vite)** for the frontend.  
The application supports complete **CRUD operations** for managing employees.

---

## 🚀 Features

- Add new employee
- View all employees
- Update employee details
- Delete employee with confirmation
- RESTful APIs
- Clean UI using Tailwind CSS
- Swagger API documentation

---

## 🛠 Tech Stack

### Backend
- Java
- Spring Boot
- Spring Web
- Swagger / OpenAPI
- Maven

### Frontend
- React (Vite)
- JavaScript
- Axios
- Tailwind CSS

---

```

employee-management-system/

```

## ⚙️ Backend Setup (Spring Boot)

1. Open the backend project in your IDE
2. Configure database (if applicable)
3. Run the application

Backend runs on:
```

[http://localhost:8005](http://localhost:8005)

```

Swagger UI:
```

[http://localhost:8005/swagger-ui.html](http://localhost:8005/swagger-ui.html)

````

---

## ⚙️ Frontend Setup (React + Vite)

1. Navigate to frontend folder:
```bash
cd employee-frontend
````

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```
